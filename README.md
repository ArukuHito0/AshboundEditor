# ASHBOUND バランス調整エディター

エディターを開くたびに、既存の公開中の本編からカード・敵・遭遇データを読み込みます。テストプレイも公開中の本編と同じスクリプトを、公開ページの読み込み順で使用します。調整画面、調整値の適用、試遊時の保存の分離はエディター側のコードが担当します。

本編の公開後にエディターを再読み込みすると、公開されたデータを取得します。直接取得できない場合は、エディター公開時に取り込んだ本編データを使います。

## ビルド

Node.js を用意し、エディターのリポジトリのルートから実行します。

```sh
node scripts/build-worker.mjs
```

成果物は `dist/server/index.js` です。公開用ビルドでは `ASHBOUND_PUBLISHED_DIST` に、公開中の本編ソースと同じコミットの `dist` を指定し、取得失敗時に使うデータを成果物に含めます。v23で使用した本編のSitesソースは `7cb3222dca2f1ca679cf9548d2aaf5feae72c461` です。
