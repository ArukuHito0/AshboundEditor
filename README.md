# ASHBOUND バランス調整エディター

エディターを開くたびに、既存の公開中の本編からカード・敵・遭遇データを読み込みます。テストプレイも公開中の本編と同じスクリプトを、公開ページの読み込み順で使用します。調整画面、調整値の適用、試遊時の保存の分離はエディター側のコードが担当します。

本編の公開後にエディターを再読み込みすると、公開されたデータを取得します。取得に失敗した場合は画面に案内が表示されます。

## ビルド

Node.js を用意し、エディターのリポジトリのルートから実行します。

```sh
node scripts/build-worker.mjs
```

成果物は `dist/server/index.js` です。エディターのビルドに本編のチェックアウトは不要です。
